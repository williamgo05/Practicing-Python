📦 Sistema de Controle de Estoque em Python

- Descrição:

Este projeto consiste em um sistema simples de controle de estoque desenvolvido em Python, executado em modo console.

O sistema permite o cadastro de produtos e o cálculo da quantidade total de itens em estoque, utilizando estruturas fundamentais da linguagem como listas, dicionários e funções.

- Funcionalidades:

✅ Cadastro de produtos

✅ Validação de código duplicado;

✅ Validação de preço e quantidade (não negativos);

✅ Cálculo do total de produtos em estoque;

✅ Menu interativo no terminal;

- Objetivo do projeto:

Este projeto foi desenvolvido como exercício prático para reforçar conceitos fundamentais de programação em Python, incluindo:

✅ Estruturas de dados (listas e dicionários);

✅ Funções;

✅ Validação de dados;

✅ Estruturas de repetição;
